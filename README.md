# Nepalese Food Science Blog

## Exploring the Science Behind Traditional Nepalese Cuisine

This project is a scientific and cultural exploration of traditional Nepalese cuisine.

It examines fermentation, microorganisms, nutrition, food preservation, biodiversity, and cultural heritage in Nepalese foods.

### Foods Discussed
- Gundruk
- Kinema
- Sel Roti
- Dhindo
- Traditional Nepalese Foods

### Objective
To explore and preserve the scientific and cultural knowledge behind Nepal's traditional culinary heritage.
